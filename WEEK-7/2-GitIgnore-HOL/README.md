## Objective

The objective of this assignment is to understand and implement the `.gitignore` file in Git to ignore unwanted files and folders from being tracked.

## Prerequisites

- Git installed
- GitHub account
- Local Git repository
- Git Bash

## Files Created

- README.md
- .gitignore

- log/app.log

```gitignore
*.log
log/
```

```bash

```
